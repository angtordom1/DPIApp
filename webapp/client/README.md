# DPIApp — cliente Vue

SPA de DPIApp (Vue 3 + PrimeVue). Ver el [README principal](../../README.md) para la arquitectura completa.

```bash
npm install
npm run serve      # http://localhost:8080 (proxy /api → http://localhost:3000)
npm run build      # genera el bundle en ../server/public
npm run lint
```

Basado en la plantilla [Sakai Vue](https://github.com/primefaces/sakai-vue) de PrimeTek (licencia MIT, ver [LICENSE.md](LICENSE.md)).
